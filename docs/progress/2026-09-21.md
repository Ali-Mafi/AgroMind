# Calm farm workspace redesign

Base: `adbcad5d05adbb123d1cc06bacf5c3c4e2ce78fd` (Phase 2.1 merged).
Branch: `ui/calm-farm-workspace`.

## UI architecture

- Scoped workspace tokens preserve the landing page and immersive Weather visuals. Light, dark and system themes use the existing ThemeProvider.
- AppShell supplies a skip link, mobile safe-area bottom navigation and a desktop sidebar. Home, Farms, Assistant and Account are the only primary destinations.
- PageHeader, BackButton, FarmSwitcher, StatusCard, SummaryCard, SectionHeader, EmptyState and LoadingSkeleton consolidate repeated presentation.
- Dashboard uses the existing farm snapshot, saved schedule and Weather hook. No inferred crop health, soil measurement or irrigation advice is fabricated.
- Farm overview retains actual Farm/Garden fields and deletion, with Weather, irrigation, crop information and an honest sensor empty state.
- Assistant has four localized question starters and a draft input. Sending remains disabled because the existing product has no connected chat service.
- Account groups profile, security, subscription, usage, preferences, help and about. Security actions and providers are unchanged.
- Forms retain their inputs, validation and mutation APIs. The unsaved-edit dialog now uses Base UI focus management and Escape behavior.

## Navigation

Each real browser history entry carries a boolean Back marker, preserving Next's existing state. It does not store tokens, paths or a synthetic history stack. Normal Back invokes router.back; external/direct entries and authentication transitions use a centrally validated parent fallback. Farm edit cancellation preserves the existing dirty-form confirmation. URL farm context is carried into Weather/irrigation and across the main navigation. Navigation has immediate progress feedback and suppresses repeated clicks on an in-flight destination.

The new Assistant route is registered with the existing private-route matcher and redirect allowlist; authentication checks themselves are unchanged.

## Preserved boundaries

No database migration, Supabase setting, schema, API, entitlement, subscription logic, farm model, cloud persistence, MFA action, session validation or RLS change. Weather's only full-page edit substitutes the shared Back icon; its styling, animations, assets, charts, providers, calculations and translations are intact. Only its workspace summary card is redesigned.
