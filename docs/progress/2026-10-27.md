# 2026-10-27 — Standard workspace edge-to-edge safe-area correction

- Starting `main`: `a351a5c1490246b2a540d02f1557262bd7d0d721`.

- In installed PWA viewports below 1024px, a noninteractive, masked/frosted fixed overlay softly obscures content as it scrolls behind the top status area without imposing a solid stripe. Web browser/desktop and non-workspace auth layouts remain unchanged.
