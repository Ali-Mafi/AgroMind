# AgroMind progress — 2026-09-23

## Post-PR #9 mobile/account follow-up

- Quick Help topic buttons now update the matching question group and smoothly scroll it into view; reduced-motion users get an immediate non-animated jump.
- Official support email is active at `support@agromind.ir`. Ticket submission remains draft-only because no ticket backend exists.
- The Assistant hides the mobile bottom navigation while its composer is focused, removes the reserved nav gap, and restores navigation on blur. Desktop navigation is unchanged.
- Persian `Controls & sensors` now reads `کنترل و حسگرها`, and the remote-irrigation and sensor cards have proper separation.
- Fixed RTL/iOS overlap between measurement values and Latin unit suffixes in Add Farm and Edit Farm by keeping unit padding/positioning in the LTR numeric input coordinate system.
- Account identity now presents Full Name and Username as separate concepts. Legacy profiles with `username = NULL` show an explicit "username not set" state rather than inferring one from `full_name`.
- Username setting/changing uses a dedicated server action, the existing availability RPC, the existing `lower(username)` unique index for final race safety, and a new MFA-gated `change_username` RPC. A fresh authenticator challenge is required for every username mutation.
- Database audit before the change found no duplicate non-null usernames. Six profiles existed: three had canonical usernames and three had `username = NULL`. Existing Auth username metadata matched canonical profile usernames where present.
- The new migration was syntax-validated in a rolled-back transaction and then applied successfully to the connected Production Supabase project as `secure_username_change`.
- GitHub Foundation checks for the branch passed lint, typecheck, application tests, native PostgreSQL tests, localization, production build and HTTP checks. Vercel preview deployment is also green.
