## Release status and remaining blockers

**Implemented, locally verified candidate; not released.** Final-head CI must be
checked on its PR. Required hosted isolated-account acceptance, independent
security review, timeout-policy verification, scheduler/credential/flag readiness,
physical iOS PWA and real inbox QA remain release blockers.

The fresh-proof guarantee applies to AgroMind server actions, not direct native
Supabase Auth endpoints. Existing provider bearer/AAL semantics and already
issued JWT/in-flight/realtime limits remain. Observation during a DB outage is
reconciled only when the session returns; direct native logins outside AgroMind
and never-returning sessions are not observable by this app path. External email
outages can outlast the safe 23-hour retry horizon. Non-login/non-revocation audit
writes can have gaps after native success during a DB outage. These residual
risks are explicit in the runbook; do not call the candidate provider-wide fresh
MFA or exactly-once inbox delivery.
