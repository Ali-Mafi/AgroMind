# AgroMind Progress — 2026-08-27

## Session Goal

Continue moving AgroMind away from demo behavior and toward a real production-ready application where operational data is either real, unavailable, or explicitly not connected.

Core rule established for the real application:

- Real data → show real value
- Source not connected → `Not connected`
- Source connected but no reading → `No data`
- Loading → loading state
- Failure → unavailable/error state
- Fake operational data → not allowed

Demo/example data is allowed only inside the Landing page.
