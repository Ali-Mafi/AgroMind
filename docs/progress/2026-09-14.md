## MFA Login Bug Fix

After TOTP was enabled, the first live sign-in test exposed a sequencing bug:

- Username/password sign-in created an AAL1 session.
- The app tried to read the protected profile/cloud state before presenting the MFA challenge.
- RLS correctly blocked that read, producing the generic `Your cloud data could not be loaded` screen.

The flow was corrected to:

`Username/Email + Password → check Authenticator Assurance Level → /mfa challenge → AAL2 → protected profile/cloud reads → destination`

This fix was covered by regression tests and deployed to production.
