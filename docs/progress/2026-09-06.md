## Technical Direction

The Weather UI should prefer accurate data semantics over decorative wording:

- `current` data describes what is happening now.
- `daily` data describes the forecast for the day.
- precipitation totals and short-interval readings must not be mixed together.
- visual effects must pause when hidden/offscreen and respect reduced-motion preferences.
